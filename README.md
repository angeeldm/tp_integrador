# tp_integrador

# GESTOR DE PAÍSES

Este programa en Python permite administrar y consultar un conjunto de datos de países almacenados en un archivo de texto utilizando un menú interactivo por consola

Descripción
El sistema carga un conjunto de datos desde paises_dataset.txt y ofrece funciones completas de visualización, búsqueda, filtrado, ordenamiento y estadísticas y los datos modificados se guardan automáticamente al salir.

Características principales:
Lectura y Escritura Automática: Persistencia de datos en formato tipo CSV 
Búsquedas Flexibles: Ignora acentos y mayúsculas al buscar nombres de países o continentes 
Validaciones Robustas: Control estricto contra ingresos vacíos, textos con números o rangos incorrectos.

Instrucciones de Uso
Requisitos: Tener instalado Python 3 y contar con el archivo de datos paises_dataset.txt en la misma carpeta que el script
Ejecución: Ejecuta el archivo principal desde la consola: python TPI.py
